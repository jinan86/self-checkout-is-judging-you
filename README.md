## The entry

> One banana. Four energy drinks. We both know how tonight ends.

## How it works

`main.py` writes the single remark to `/output/entry.txt`. Nothing else: no network, no secrets, no dependencies — just the line, exactly as the machine would say it.

```bash
python3 main.py
cat /output/entry.txt
```
